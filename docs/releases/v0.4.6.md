# v0.4.6

## 修复

**弹窗在「有对话」时偏右，空会话却正常。**

你这条线索直接定位了问题：两种布局下槽位落在**不同的容器**里。原判据取「第一个比视口窄的祖先」—— 工具栏、浮层这类局部容器全都比视口窄，空会话时第一个命中的恰好是居中那层，一有对话就命中偏右的那个。

`0.4.5` 试过「取最宽的」，仍不准：更上层可能有"比视口窄、但位置偏右"的包裹层被选中。

现在改为**取第一个「够宽」的祖先**（宽于视口 30%）：工具栏、浮层、单行按钮组都在三成以下被跳过；输入卡片与对话列一定在三成以上，而且它们紧邻槽位。

## 自证

遮罩上的 `data-dsh-prompt-frame`：

- `column:<left>/<width>` —— 按这一列定位，附带实际数值
- `viewport` —— 没测到列，退回整视口居中

若位置仍不对，把那个值发我即可定案。

装完**重启 DSH**。本机已是 link 装 0.4.x，重启后直接生效。
