# v0.4.4

## 新功能

**任务扩写。** 输入框工具栏新增「任务扩写」按钮：把输入框里那句话扩写成可以直接发送的完整任务，**原地回填**，不弹窗。用的是你当前对话的模型。

扩写遵守几条明确约定：不出现「角色:」「目标:」这类字段标签（产物是正文，不是表单）；专有名词照抄不改写；原文没写但执行必需的细节（验收、边界、信息不足怎么办）要补，但**没有依据的不凭空断言**，只能写成条件句；长度控制在原文的两到四倍。

**不会覆盖你期间的新输入**：请求要等十几秒，如果这期间你又往输入框补了字，结果回来时不会被整段替换 —— 按钮会提示「草稿已改动」，你的字留着。

## 改进

**工具描述重写。** 之前那段说明三次强调"成本高、简单任务跳过它"，还把唯一用途写成"把结果传给 subagent 工具" —— 而 `delegate` 在本版 DSH 不可用。结果就是模型在派遣子代理时几乎不选它。现在按决策点组织：先用一段列出"什么时候该用"的识别信号，再说它相比随手写一段好在哪，最后才提"什么时候可以省"且条件收紧。`delegate` 的描述也如实标注"当前版本不可用"。

**三级模型回退抽出成一处。** 会话正在用的模型 → 宿主默认模型 → 装载行配置，自动填充、转化、任务扩写共用同一份实现，不会再出现三处各写一套、其中一处漏掉默认模型的情况。
