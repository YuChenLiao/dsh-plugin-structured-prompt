# v0.5.0

## 变更

**表单不再用弹窗，改挂宿主侧栏。** 弹窗定位在真机上一直修不干净，这次不是再修一次坐标，而是把外壳换掉：位置与尺寸交给宿主，插件不再测量任何东西。

侧栏按优先级取第一个能用的：

1. **`dsh-better-sidebar`** —— 表单与文件树 / 编辑器 / 变更并列在你日常用的那一列；
2. **宿主原生右侧栏** —— 没有 better-sidebar 时的等价落点；
3. **弹窗** —— 两个都没有时（旧宿主）才回到这里，并在弹窗顶部写明缺的是哪个服务。

装哪个都行：三者共用同一份表单状态，入口按钮、弹窗、两个侧栏 tab 里看到的永远是同一份内容。

## 使用

点输入框左侧的「结构化输入任务」，表单出现在侧栏。侧栏 tab 自带关闭手势，标题栏不再重复一个 ×。

## 自证

- 侧栏里没出现表单时，弹窗顶部那行会写出三个服务各自的可见性
  （`betterSidebar=有/无 / sidebarRightTabs=… / sidebarRight=…`），以及是"注册失败"还是"打开失败"及原因。
- 打开失败不会变成"按了没反应"：插件会退回弹窗。

## 升级

装完**重启 DSH**。本机已是 link 装，重启后直接生效；从 npm 装的话 registry 仍停在 0.4.1（发布凭据的老问题），建议用 GitHub 源或本地 link。

## 已知边界

- 「提示词库」的检索弹窗**没有**迁移，仍是弹窗（先验证通路，再决定要不要一起迁）。
- 产物末尾不带换行（`buildSystemPrompt` 的输出不以 `\n` 结尾），修它要动黄金样本，仍未做。
- `convert` 只有布尔防连点，没有请求序号（`expand` 有）。
