# v0.3.2

## 修复

**弹窗在右侧栏打开时位置偏了。** 结构化表单与提示词库的弹窗原来按**整个窗口**居中；右侧栏打开时对话列变窄，弹窗就偏右、被右栏压住。现在按弹窗自己所在的**那一列**居中，右侧栏开合与窗口缩放都会跟随。测不到那一列时（还没布局好）退回原来的整视口居中。

## 变更

**样式从 ts 文件搬进真正的 CSS 文件**，采用与 DSH 官方客户端包相同的方案（lightningcss 在构建期编译 + 自动注入）：

- 全局那份在 `src/shared/ui/panel.css`；组件引用的类在 `src/shared/ui/panel.module.css`，类名在构建期 hash，不污染全局。
- 颜色一律用宿主的 `--dsw-*` 变量，不再在插件里固化主题。
- 删掉了原来的内联样式对象与手写的样式注入逻辑 —— 注入现在是构建产物的责任，幂等由生成的模块保证。
- 顺带消掉一处重复：文本域高度上限原来在 JS 与样式里各写一份，现在只有一处（JS 从计算样式读）。

对使用者没有可见变化，除了弹窗位置。

## 升级

```powershell
dsh plugin --profile desktop add github:YuChenLiao/dsh-plugin-structured-prompt
```

装完**重启 DSH**（host 侧注册发生在启动时）。

## 已知边界

弹窗定位在真实浏览器里的表现（右侧栏开合时是否即时跟随）建议重启后看一眼 —— 离线测试只能断言「基准取的是那一列」与「rect → 样式的映射是纯函数」，测不了真实布局。
