# v0.4.2

## 修复

**「自动填充」报「读不到当前对话的模型」。** 根因是**服务可见性**：自动填充的请求处理跑在
`ctx.inject(['connection'])` 给出的**作用域上下文**里，而 `sessions` / `sessionProjections`
未必在那儿可见。上一版只在这个上下文里找模型，找不到就返回空 —— 界面上只剩一句"读不到模型"，
看不出是服务不可见、会话取不到、还是投影还没有状态。

现在两个上下文都试，并且失败时**说明卡在哪一步**：

- `拿不到 sessions 服务`
- `sessions.get('<id>') 没有返回会话（这个会话可能已结束）`
- `拿不到 sessionProjections 服务`
- `这个会话还没有模型选择（先在本会话里发一条消息，让它跑过一轮请求）`
- `投影里没有可用的 provider / model`

另外 `sessionProjections` 取不到时会兜底从 `sessions.scope(id)` 上取。

## 升级

装完**重启 DSH**。

## 如果仍然报错

把错误消息括号里那句原因告我 —— 它指向具体环节，比"读不到模型"好定位得多。
