# v0.3.3

## 修复

**弹窗按对话列居中（第二版）。** v0.3.2 的修复没有生效：它只读取遮罩的**一层**父元素作为定位基准，而槽位的包装层数在不同 DSH 版本里不一样 —— 那一层可能仍是整宽容器，于是测出来正好等于视口宽，弹窗照旧按整个窗口居中。

现在改为从遮罩**向上找第一个比视口窄的祖先**（右侧栏展开后中间列必然窄于视口），它就是被挤压过的那一列；找不到时退回整视口居中。判据里没有任何宿主内部结构，不会随版本碎。

另外给遮罩加了一个可自证的属性，便于区分"没生效"与"生效了但期望不同"：

```js
// 浏览器控制台：'column' = 已按那一列生效；'viewport' = 退回整视口居中
document.querySelector('[data-dsh-prompt-mask]')?.dataset.dshPromptFrame
```

## 已知边界

- 若右侧栏处于全屏 / 覆盖模式（中间列并不变窄），"按列居中"与"按视口居中"等价 —— 那种模式下本插件不会自动避让。
- 右侧栏开关一瞬是否即时跟随，建议在真实界面确认一次（离线测试只能断言"基准是那一列"与"rect → 样式的映射"）。

## 升级

```powershell
dsh plugin --profile desktop add github:YuChenLiao/dsh-plugin-structured-prompt
```
