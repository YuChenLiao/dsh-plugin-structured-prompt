# v0.4.0

## 新功能

**自动填充表单。** 表单顶部多了一行：写一句需求，点「自动填充」，模型把这句话扩写成结构化字段填进表单。用的是**你当前对话的模型**，不需要任何配置。

**提示词库原文 → 表单。** 提示词库详情页多了「转化为表单」：把检索到的成品提示词拆解成字段，直接填进表单并打开它。与「发送原始提示词」是两条路 —— 那条把原文发进对话，这条只改表单，**对话里不留任何痕迹**。

两条都不经过主对话上下文：请求从界面直接到宿主，结果也只回到界面。

## 行为约定

- **只补不改**：自动填充只合并模型返回的字段，不会清空你已经填好的其它字段。
- **校验后才落地**：模型输出必须逐字段过校验；未知键、类型不符会被丢弃，并在界面上说明丢弃了几处。宁可补不全，也不写入来路不明的内容。
- **模型取自当前会话**：如果这个会话还没发过任何请求（所以还没有模型选择），会提示"读不到当前对话的模型"，发一条消息后重试即可。
- **子代理路径不可用**：本版 DSH 的 `subagents.start` 不向插件暴露，工具的 `delegate` 参数会报一句可读错误（含该句柄实际暴露的方法名）。自动填充因此走单次调用，不依赖它。

## 升级

装完**重启 DSH**（host 侧注册发生在启动时）。

## 已知边界

- 真实模型输出质量只能上线看：模型是否老实只输出 JSON、会不会漏字段 —— 漏字段只会"补不全"，不会"清空"。
- 没有取消按钮：等待上限 90 秒，关掉弹窗后请求仍在跑，结果回来时仍会合并进表单。
