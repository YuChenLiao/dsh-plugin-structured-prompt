# v0.4.5

## 修复

**弹窗定位偏右。** 定位基准的判据原来是「从遮罩向上第一个**比视口窄**的祖先」。槽位容器常常被渲染在某个局部容器里（工具栏、某个浮层），它们全都满足这个条件 —— 第一个命中的就是那个小容器，遮罩于是贴着它，弹窗跑到窗口右侧。

现在改为取**链上最宽的那个**窄祖先：越往上越宽，最宽的必然最接近真正的对话列。

**自证锚点带上了数值。** 遮罩的 `data-dsh-prompt-frame` 从 `column` / `viewport` 两态改为 `column:<left>/<width>` —— 出问题时截图就能看到实际算出的位置与宽度，不用再猜。

## 一句实话

这个改法是基于「遮罩被渲染进局部容器」的**推断**做的，我手上没有真实环境里遮罩的 DOM 证据。如果重启后位置仍不对，把遮罩上 `data-dsh-prompt-frame` 的值发我（开发者工具里选中遮罩元素就能看到），那是定案唯一需要的数。

## 升级

装完**重启 DSH**。本地可直接 `link:` 装最新：

```powershell
dsh plugin --profile desktop remove dsh-plugin-structured-prompt
dsh plugin --profile desktop add link:D:\dsh\dsh-plugin-structured-prompt
```
